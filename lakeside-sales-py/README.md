# Lakeside Village Property Sales Map

Modern, interactive property sales mapping application built with Streamlit.

## Features
- 🗺️ Interactive map with pan/zoom
- 🔍 Search and filter properties
- 📊 Real-time status updates from Google Sheets
- 📱 Mobile-responsive design
- 📧 Lead capture forms
- 📈 Analytics tracking

## Installation

```bash
# Create virtual environment
python -m venv venv

# Activate (Windows)
venv\Scripts\activate

# Activate (Mac/Linux)
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

## Configuration

Create a `.env` file:
```
GOOGLE_SHEETS_URL=your_sheet_url_here
CONTACT_EMAIL=sales@lakesidevillage.com
```

## Running

```bash
streamlit run app.py
```

## Deployment

Deploy to Streamlit Cloud for free hosting.
